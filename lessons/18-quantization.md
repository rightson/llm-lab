# 18｜用更少 bits，代價是什麼？

如果大量時間花在搬權重，縮小每個權重就有機會降低容量與頻寬需求。Quantization 把連續數值近似到較少的離散等級。

最簡單的對稱量化先選尺度 s，把數值映射成整數 q=round(w/s)，再用 ŝ=q×s 還原。假設 s=0.1，w=0.26 會被近似成 0.3，誤差為 0.04。不同 tensor、channel 或 group 可有不同尺度。

本實驗用 signed b-bit 的對稱範圍 −(2^(b−1)−1) 到 +(2^(b−1)−1)，並令 s=max|w|/(2^(b−1)−1)。它是示範用設計，不代表所有量化格式。

執行 `python -m labs.run quantization`，比較 8-bit 與 4-bit 還原誤差。陣列中有一個較大的 4.0，會拉大共同尺度，使其他小數值的精度變差；這說明 outlier 與分組方式為何重要。

| 量化對象 | 直接影響 |
| --- | --- |
| Weights | 固定模型大小與讀取流量 |
| Activations | 中間運算與部分資料搬移 |
| KV cache | 隨 context/併發增長的狀態 |

只量化 weights 不會自動讓 KV 也縮小。4-bit 的名目大小約是 16-bit 的四分之一，但實际還有 scales、metadata、未量化層與對齊成本。速度也取決於核心是否能高效讀取、解包與運算。

模型品質應用實際任務測量：例如程式測試通過率或結構化輸出正確率，而不是只看張量平均誤差。某些小誤差可能改變下一個 token，接著影響整段生成。

**練習：** 16-bit 改成 4-bit 後模型裝得下，能否宣稱速度四倍且品質不變？

**答案：** 不能。容量、速度與任務品質是三種不同結果，需要分別量測。

**延伸閱讀：** [AWQ](https://arxiv.org/abs/2306.00978)，觀察實際方法如何處理不同權重對結果的重要性；本實驗沒有實作 AWQ。
