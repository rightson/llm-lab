# 02｜模型什麼時候學習，什麼時候回答？

如果只有一張手寫的接字表，模型遇到陌生句子就無法處理。我們需要一套可調整的計算規則，讓很多句子共享同一批參數。參數通常稱為 weights：它們決定輸入數字經過運算後，會給哪些候選 token 更高分。

**訓練**反覆做三件事：預測、比較正確答案、修改參數。**推論**使用已有參數，計算新的輸出。聊天時把新的訊息加進 context，通常改的是這次運算的輸入，而非模型權重。

以「a b a」為例，可以建立兩個訓練題：「a」之後是 b；「a b」之後是 a。若模型把正確答案的機率設為 p，常用損失為：

$$L=-\log p$$

p=0.8 時，損失約 0.223；p=0.2 時約 1.609。正確答案的機率越低，處罰越大。梯度告訴我們參數往哪個方向微調能降低損失；學習率決定每次走多大步。多個題目的損失通常取平均。

執行 `python -m labs.run training`。這是只看前一個字元的 bigram 模型，會真正更新參數。它沒有 Transformer，目的是把「學習」縮小到看得懂的程度。你會看到交叉熵下降，並看到 a 後面的字元機率。

為什麼不能降到零？在教材資料裡，a 之後可能是 b、c 或空白；只看前一個字元，本來就不足以唯一決定答案。增加參數以外，也可能需要更好的輸入資訊與模型結構。

正式聊天模型通常還有預訓練後的調整，使它更能遵循指令。這些訓練階段不改變本系列先研究的核心問題：給定權重與前文，下一步如何算出來？

**練習：** 聊天時貼入一段最新新聞，算不算模型學會並永久記住了新聞？

**答案：** 只能確定它能在這次 context 中使用新聞。是否另行保存或拿去訓練是系統政策，不能從「它現在答得出來」推論權重已更新。
