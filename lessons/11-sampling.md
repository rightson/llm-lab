# 11｜同一個模型，為什麼每次回答不同？

即使 logits 相同，選 token 的規則不同，結果也可能不同。Greedy 永遠取分數最高者；sampling 則按機率抽樣。前者決定性較強，後者允許探索多條輸出路徑，但都不自動保證答案正確。

Temperature T 先把 logits 除以 T，再做 softmax。T 小於 1 時分布通常更集中；大於 1 時更平坦。T=0 在程式中另行定義為 greedy，不能真的除以零。

Top-k 只保留分數最高的 k 個候選。Top-p 先依機率排序，保留累積機率達到 p 所需的最小前綴，然後重新正規化。

假設分布為 [0.6,0.3,0.1]，top-p=0.8：第一個只累積到 0.6，還不夠；必須連第二個一起保留，雖然總和會到 0.9。重新正規化後是 [2/3,1/3,0]。不能把「跨過門檻」的 token 刪掉。

執行 `python -m labs.run sampling`，比較 temperature、top-k 與 top-p。程式的套用順序是 temperature → top-k → top-p。不同服務可能有不同組合限制或實作細節；記錄參數時也應記錄服務與版本。

固定 random seed 可改善同一環境的可重現性，但跨裝置、核心與版本仍可能因浮點結果不同而產生不同序列。尤其當兩個候選分數接近時，微小差異可能經過多步生成而擴大。

**練習：** 降低 temperature 可以讓一個原本最偏好的錯誤答案變正確嗎？

**答案：** 不保證。它可能只是更穩定地選中那個錯誤答案。Temperature 改變選擇分布，不會補上缺少的證據。

**完成標準：** 能手算 top-p 保留集合，並區分創意、多樣性、可重現性與正確性。
