# 06｜為什麼每個位置需要讀取其他位置？

「小明把書交給小華，因為他要回家。」只看最後一個字的向量，不足以處理句子的關係；模型需要把前文資訊帶到目前的位置。但直接把所有向量平均，又會抹去與當前問題有關的差異。

Attention 提供一種依輸入調整的加權讀取。對每個位置，從當前表示產生三個向量：Q 決定如何查詢；K 決定如何與查詢配對；V 是最後被加權合併的內容。三者都是矩陣投影的結果，不是額外儲存的一套文字問答。

先看一個極小算例。查詢 q=[1,0]，兩個 key 是 [1,0] 和 [0,1]。點積分別為 1 和 0。經過縮放與 softmax 後，第一個位置得到較高權重；再用這些權重混合兩個 value。

執行 `python -m labs.run attention`，你會得到約 [0.670,0.330] 的權重。若 values 是 [10,0]、[0,20]，加權結果約為 [6.698,6.605]。

注意：結果不是「挑中第一個位置後把另一個丟掉」，而是這兩個 value 的混合。學習到的 Q、K 可以使不同輸入產生不同混合比例。

這種機制讓資訊跨位置流動，但 attention 權重不等於完整的因果解釋。最終結果還經過多個 head、多層、殘差與 FFN；看到某個位置權重高，不能直接斷定模型只靠那個字回答。

**練習：** 把 q 改成 [0,1]，其他數值不變，哪個 value 的權重會提高？

**答案：** 第二個。可在程式中改 q，重新執行，確認輸出向量往 [0,20] 的方向移動。

**完成標準：** 能用自己的話區分「配對分數」與「被讀出的內容」，並手算兩個 value 的加權和。
